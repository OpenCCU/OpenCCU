# Home Assistant App: OpenCCU (snapshot)

**WARNING**:
This version of the Home Assistant App of OpenCCU is an **experimental** build snapshot version. It is **NOT** meant to be used in production environments as it may contain severe bugs or incompatibilities which could destroy your installation/configuration. It is meant to be used for internal tests of new features and intermediate bugfixes only. Use of this experimental build is therefore at your own risk.

If you are looking for the stable/latest version of the Home Assistant App of OpenCCU please use the non-snapshot version in this App repository.

For setup and documentation on how to use this app please refer to the documentation of the stable/latest version.
